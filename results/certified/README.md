# Certified Evidence

`general_d` contains the validated historical artifact list: `cert_d2_k3`, `cert_d2_k4`, `cert_d4_k2`, `cert_d5_k2`, `struct2_d2_k5`, `struct2_d3_k3`, `struct3_d4_k3`, `y3_d4_k4`, and `y3_d5_k3`. `kcopy_d2` contains final exact per-k MATs for k=1 through 4.

The `cert_*` files contain full-space certificate metrics. `struct3_*` and `y3_*` are reduced-space certificates; their PSD metrics refer to reduced blocks, as documented in the support logs. `strict_submult_C_sparse.tsv` is the historical sparse rational certificate and uses one-based indices.
