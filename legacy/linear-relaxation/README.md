# Linear Relaxation Archive

These scripts retain the historical m=0,1 linear relaxation only. It is a
lower bound, not equivalent to the exact SDP, can lie below the exact optimum,
and must not be cited as gamma_k. It is distinct from the prototype's full
raw-row mode; a matching number does not make the relaxation exact.

The original k=1..4 parameters are preserved. This is a legacy provenance
runner and not a supported result-producing entry point.
